# status / help

## `status`

### Synopsis

```
gov status
```

### Purpose

Report the current state of the comfy_env project — configuration readiness, environment health, and recent transaction activity.

### Reads

- `config.toml` — all sections
- `pyproject.toml` — dependency groups (check torch/core readiness)
- `state/plugins.json` — plugin count
- `state/transactions/*.json` — recent transactions
- `.venv-prod/` — existence check
- `state/comfyui.pid` — running status

### Writes

Nothing.

### Success Path

```
1. Check config readiness:
   - config.toml exists? → config_ready
   - paths.comfyui_dir set and valid?
   - runtime.python set?
2. Check environment readiness:
   - .venv-prod/ exists? → prod_env_exists
   - dependency-groups.torch populated? → torch_ready
   - dependency-groups.core populated? → core_ready
3. Report plugin status:
   - Number of registered plugins
   - Number of enabled plugins
4. Report transaction status:
   - Count by status (pending, completed, failed, needs_resolution)
   - List last 8 transactions (txid, kind, status, subject, timestamp)
5. Report running status:
   - PID file exists? Process alive?
6. Print formatted summary to stdout
```

## `help`

### Synopsis

```
gov help
```

### Purpose

Display usage information for all commands.

### Writes

Nothing.

### Behavior

Print structured help text covering all command groups, their synopses, and brief descriptions. In the Rust implementation, this is auto-generated by `clap`'s derive macros.
